# EcoXAI: IoT-Driven Water Footprint Intelligence for AI Data Centres and Crypto Mining

## About
EcoXAI is an original IoT-enabled Explainable AI framework that monitors and intelligently explains water footprint in AI Data Centres and Cryptocurrency Mining.

## Problem
Data centres and crypto mining consume millions of litres of fresh water daily for cooling. Nobody knows WHICH factor wastes the most water.

## Solution
EcoXAI uses IoT sensors + Machine Learning + XAI to:
- Monitor water usage in real time
- Predict future water consumption
- EXPLAIN which factor wastes most water
- Recommend what to fix first

## Key Findings
- Temperature = Biggest water waster
- Crypto Mining = Doubles water consumption (72%)
- Critical risk data centres = 4x more water than low risk
- Hyderabad data centres consume most water in India

- Python
- Google Colab
- Machine Learning (Random Forest)
- XAI (SHAP)
